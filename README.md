# Minecraft server.properties Generator

Erstelle deine server.properties per Klick: MOTD, Schwierigkeit, Spielmodus, Sichtweite, Whitelist und mehr. Mit Erklärung und Download.

**Online nutzen:** [Minecraft server.properties Generator](https://ventrohosting.com/tools/minecraft-server-properties-generator) · Demo: https://ventrohosting.github.io/minecraft-server-properties-generator/

## Funktionen

- MOTD, Spielmodus, Schwierigkeit, Sicht- und Simulationsweite, Spawn-Schutz, Seed, PvP, Whitelist und mehr
- Umlaute und Sonderzeichen korrekt als \uXXXX-Escape
- Kopieren oder als Datei herunterladen, alles im Browser

## English

Minecraft server.properties generator: set MOTD, game mode, difficulty, view/simulation distance, spawn protection, seed, PvP, whitelist and more, then copy or download the file. Runs entirely in the browser.
